# Saarthi (सारथि) - Nepal Civic & Financial Digital Platform

Saarthi is a modern, unified civic technology platform designed for public access in Nepal. It empowers citizens with fast, intuitive access to public services, tax estimation tools, NEPSE stock market updates, banking utilities, vehicle tax calculations, and official notice guidance.

## Core Services & Features

- 🏛️ **Civic & Public Portals**: Access guides and direct links for Nagarik App, e-Passport, National ID (NID), Driving License, & IRD services.
- 📈 **NEPSE Stock Market & Financials**: Real-time stock indices, top gainers/losers, sector breakdown, and portfolio WACC tools.
- 🚗 **Bluebook & Vehicle Tax Manager**: Provincial vehicle tax estimations, renewal deadlines, third-party insurance, and PDF summary exports.
- 💵 **Income Tax Calculator**: Complete Nepal IRD income tax slab breakdown with instant PDF report generation.
- 📅 **Bikram Sambat (B.S.) Calendar**: High-precision B.S. / A.D. date converter, daily Panchanga, and official public holidays.
- 📜 **Notice & Gazette Breakdown**: Rule-based official gazette notice breakdown engine to analyze public circulars in English and Nepali.
- 🛡️ **Operations & Admin Management**: Multi-role platform administration (Super Admin, Admin, Moderator, Support) with live activity logging, service fee management, and system monitoring.

## Technology Stack

- **Frontend**: React 18+, TypeScript, Vite, Tailwind CSS, Lucide Icons, Motion
- **Backend**: Express.js (Node.js + TypeScript)

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

The application will run on `http://localhost:3000`.
